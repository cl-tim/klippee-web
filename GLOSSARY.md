# Klippee

Klippee keeps printer files and slicer profiles for its users.

## Language

**Physical printer**: A device, such as example1, which can use several printer profiles.
_Avoid_: Profile

**Printer profile**: Slicer settings for a printer configuration, including nozzle size. A profile can be used with more than one physical printer.
_Avoid_: Printer record

**Profile library**: A user's saved printer, process and filament profiles, independent of their physical printers.

**Saved setup**: A captured combination of a printer profile, a process profile and ordered filament slots, including captured unsaved edits.

**Custom profile**: A profile that OrcaSlicer identifies as a user profile, regardless of its name.
