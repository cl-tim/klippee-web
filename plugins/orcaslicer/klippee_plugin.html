Klippee

Save to Klippee

Import enabled printer profiles and all custom process and filament profiles into your private library. Nozzle variants stay separate. Physical printers are linked optionally in Klippee.

Review each upload before confirming. Profile imports replace your library backup; setup saves add a new snapshot with all filament slots and unsaved edits. No printer actions are sent. Enable imports and saves for this installation in Klippee first.

In Klippee, open Orca Workspace and choose Import from OrcaSlicer to create a code. A saved-setup code captures only your current combination instead.

      Custom G-code is included. Review it for personal information before saving. No models or printer actions are sent.

      Browse your Klippee library

      In Klippee's Orca Workspace choose Browse library in OrcaSlicer. Paste the connection code once. This Orca installation stays connected after restarts until you disconnect it here or in Klippee. Browsing and restoring are always available. Imports and setup saves need the permission enabled in Klippee and your confirmation for each upload. Nothing syncs automatically.

      Restore from a file

      In Klippee, choose Export profile for OrcaSlicer on a library profile, or Export saved setup. Open the JSON file here to restore separate copies with their full inheritance.

      Your original presets, current selections, unsaved edits and models stay unchanged. Restoring again creates another set of copies. No printer actions are sent.

      Review the saved profile or setup

        Custom G-code is included and can run when you later print. Only restore files you trust. Printer connection credentials are excluded.

        Restored copies

        For an individual profile, select the listed copy in Prepare when needed. Your other selections and filament slots stay unchanged. For a complete setup, Orca requires manual selection after restore. Choose the printer first, then process, then each filament slot below. Add or remove filament slots to match this list. These names belong to the new copies. Keep or save any current edits if Orca asks.
